# Claude 명령어: i18n

다국어(한국어/영어/일본어) 번역 키 추출 및 번역 파일을 관리합니다.

## 사용법

```
/i18n extract <파일경로|폴더경로>
/i18n translate <번역키>
/i18n add <번역키> "<한국어>" "<영어>" "<일본어>"
/i18n check
/i18n sync
```

## 지원 언어

| 코드 | 언어 | 파일명 |
|------|------|--------|
| `ko` | 한국어 (기본) | `ko.json` |
| `en` | English | `en.json` |
| `ja` | 日本語 | `ja.json` |

## 명령어 설명

### extract - 번역 키 추출
```
/i18n extract src/components
/i18n extract src/pages/dashboard.tsx
```
- 코드에서 `t('key')`, `t("key")` 패턴 추출
- 신규 키 발견 시 번역 파일에 추가
- 한국어 기준으로 영어/일본어 번역 생성

### translate - 특정 키 번역
```
/i18n translate common.button.save
```
- 해당 키의 3개 언어 번역 생성/수정
- 기존 번역이 있으면 확인 후 업데이트

### add - 번역 직접 추가
```
/i18n add common.greeting "안녕하세요" "Hello" "こんにちは"
```
- 3개 언어 번역을 직접 지정하여 추가
- 기존 키가 있으면 덮어쓰기 확인

### check - 번역 누락 확인
```
/i18n check
```
- 언어별 누락된 키 목록 출력
- 미번역 항목 하이라이트
- 사용되지 않는 키 감지

### sync - 번역 파일 동기화
```
/i18n sync
```
- 모든 언어 파일의 키 구조 동기화
- 누락된 키에 placeholder 추가
- 알파벳 순 정렬

## 추출 패턴

다음 패턴을 인식하여 키 추출:

```typescript
// 지원하는 패턴
t('key')
t("key")
t(`key`)
i18n.t('key')
useTranslation().t('key')
<Trans i18nKey="key" />
```

## 번역 규칙

### 한국어 (ko) - 기준 언어
- 존댓말 기본 (합쇼체 또는 해요체)
- 버튼: 명사형 ("저장", "취소")
- 메시지: 완결형 ("저장되었습니다")

### 영어 (en)
- 버튼: 동사 원형 또는 명사 ("Save", "Cancel")
- 메시지: 완결형 ("Saved successfully")
- Title Case for headings

### 일본어 (ja)
- 존경어(敬語) 사용
- 버튼: 명사형 ("保存", "キャンセル")
- 메시지: です/ます체 ("保存されました")

## 프로세스

1. **프로젝트 구조 확인** - locales 폴더 위치 감지
2. **기존 번역 파일 로드** - 없으면 생성
3. **명령어 실행** - extract/translate/add/check/sync
4. **번역 생성** - 한국어 기준으로 영어/일본어 번역
5. **파일 업데이트** - JSON 포맷 유지, 키 정렬
6. **결과 리포트** - 추가/수정/누락 현황

## 규칙

- **한국어가 기준** - 한국어 먼저 작성, 다른 언어로 번역
- **키 네이밍**: `영역.기능.항목` 형식 (예: `dashboard.chart.title`)
- **중첩 구조 유지** - flat하지 않고 의미있는 그룹핑
- **Placeholder 지원** - `{name}님 환영합니다` → `Welcome, {name}`
- **복수형 처리** - 필요시 `_one`, `_other` 접미사
- **기존 번역 보존** - 덮어쓰기 전 확인

## 설정 파일 처리 순서

1. 프로젝트 루트의 `i18n.config.json` 확인
2. 없으면 `locales/` 또는 `public/locales/` 자동 감지
3. 둘 다 없으면 기본값으로 `locales/` 생성 제안

### i18n.config.json 예시

```json
{
  "defaultLocale": "ko",
  "locales": ["ko", "en", "ja"],
  "localePath": "public/locales",
  "keySeparator": ".",
  "nsSeparator": ":"
}
```

## 예외 상황 처리

### locales 폴더를 찾을 수 없음
- `locales/` 또는 `public/locales/` 생성 여부 확인
- 사용자 선택에 따라 자동 생성

### JSON 파싱 오류
- 해당 파일 백업 후 수동 확인 요청

### 번역 키 중복
- 기존 값 표시 후 덮어쓰기 여부 확인
